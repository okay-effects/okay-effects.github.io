Local models, managed from your Mac.

okay-mlx is a native macOS control panel for a local language-model server. Install the server, download models from Hugging Face, manage automatic startup, and see how much memory and CPU the process uses.

Install the app, then the server

  1. Download and unzip the archive, then move okay-mlx.app to your Applications folder.
  2. Open the app. On a Mac without the server, choose Install server in Overview.
  3. The app downloads the server and its MLX libraries from GitHub Releases, verifies the archive checksum, and downloads the startup model from Hugging Face if it is missing.
  4. When setup finishes, the server starts at http://127.0.0.1:8090. It also starts when you log in to macOS. Use the panel to stop, restart, or disable automatic startup.

This community build is ad-hoc signed and has not been notarized by Apple. If macOS blocks the first launch, read Apple's guidance before deciding to open it. Opening downloaded apps on macOS.

The binaries and libraries are installed under ~/.okay-mlx. The initial model is mlx-community/Qwen3.5-4B-MLX-4bit. Model downloads can be several gigabytes and need sufficient free disk space and memory.

Download a model by its Hugging Face ID

Open Models, enter an ID such as mlx-community/Qwen3-0.6B-4bit, and press Download. The progress display shows the file and downloaded size. You can cancel and retry using the files that already finished.

The downloader accepts the Qwen3 and Qwen3.5 architectures supported by okay-mlx. Qwen3.6 and Qwen3.8 repositories using the Qwen3.5 architecture are supported too. Completed models appear in the list even while the server is stopped.

By default models are stored in ~/.cache/huggingface/hub. The panel also reads a service's HF_HUB_CACHE or HF_HOME setting.

A client selects a downloaded model by its exact repository ID in the request's model field. The server keeps one model active at a time and waits for current generations before switching. The model highlighted in the panel is the active one.

See and control the local server

Service and startup

See API availability, the active model, and the server address. Start, stop, and restart the service, or change whether it starts at login.

Memory and CPU

The Resources tab shows current and peak process memory, CPU load, disk reads and writes, and the Mac's memory pressure and swap usage. It refreshes every two seconds while open.

Models and downloads

Download without installing a separate command-line tool. Incomplete downloads stay out of the server's model list until all required files are present.

Service log

Read the latest server messages and locate the full log in Finder. The app follows the macOS language preference, with English, Ukrainian, and Russian translations.

Built on okay-llm and MLX

The server exposes OpenAI-compatible chat completions and an Anthropic-compatible messages API for local clients and coding agents. It uses okay-llm for the gateway and effects, and mlx-scala for inference on Apple's MLX. The control panel is written in SwiftUI.
